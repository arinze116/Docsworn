What this deployment is—and is not.

It is a truthful, accessible rendering of the deterministic fixture report and the product method.

It is not a hosted Kane runner, a live repository upload form, or evidence of a current authenticated Kane execution.

The CLI remains the source of generated flows, runner exit codes, observations and documentation suggestions.
